## 二、下次迭代方向（V11）

### 方向 1：企微 WebSocket 对接 + 双平台联调

**优先级：最高**  
**目标：** 企微也能收发消息，双平台并行

| 任务 | 说明 | 复杂度 |
|------|------|--------|
| 企微 WebSocket 接入 | 对接 wecom-aibot SDK，实现企微消息收发 | 高 |
| 双平台消息统一测试 | 飞书 + 企微同时在线，Agent 按团队配置路由 | 中 |
| 命令路由 `/电商 业绩` | 前缀指令自动路由到对应团队 Agent | 中 |
| 审批通知推送到 IM | 新审批自动推送到老板飞书/企微 | 中 |

**交付标准：** 飞书和企微同时在线，消息双向流通，审批卡片实时推送。

---

### 方向 2：Agent 多轮对话 + Tool Use

**优先级：高**  
**目标：** Agent 不只是单轮问答，而是能调用工具完成复杂任务

| 任务 | 说明 | 复杂度 |
|------|------|--------|
| 多轮对话状态保持 | 基于 conversations 表的上下文延续 | 中 |
| Tool Use 调用 | Agent 通过 function_call 调用 builtin skills | 高 |
| 子 Agent 编排 | Director → Analyst/Coach/Executor 分工 | 高 |
| 对话记忆回溯 | 引用历史对话内容进行追问 | 中 |

**交付标准：** 用户说"帮我查一下上周 KPI"，Agent 调用 sqlite_data 查数据后返回结果。

---

### 方向 3：数据对接 — 打通外部系统

**优先级：中**  
**目标：** 系统不只吃手动输入的数据

| 任务 | 说明 | 复杂度 |
|------|------|--------|
| 飞书多维表格对接 | 通过飞书 API 读写多维表格，实现数据同步 | 中 |
| 外部 Webhook 接收 | 接受 ERP/店铺平台的数据推送 | 低 |
| Excel 智能解析增强 | 上传 Excel 后 AI 自动理解结构并入库 | 高 |
| RPA 对接预留 | 预留 RPA 工具调用接口 | 低 |

---

### 方向 4：安全加固 + 运维

**优先级：中**  
**目标：** 生产环境级别的安全和可靠性

| 任务 | 说明 | 复杂度 |
|------|------|--------|
| 域名 + HTTPS | 正式域名、SSL证书、Nginx 反代 | 低 |
| 数据库自动备份 | 定时备份 SQLite + 异地存储 | 低 |
| 单元测试框架 | pytest 基础测试覆盖 | 中 |
| CI/CD 管道 | GitHub Actions 自动测试部署 | 中 |

---

### 方向 5：多租户与商业化（长期）

**优先级：低**

| 任务 | 说明 | 复杂度 |
|------|------|--------|
| 多租户隔离 | 每个公司独立数据库/schema | 高 |
| 计费系统 | Token 消耗计费、套餐管理 | 高 |
| 公开注册 | 注册页、邮箱验证、首次配置向导 | 中 |

## 四、推荐的 V11 开发计划

### 阶段 1（1周）：企微 + 双平台联调

```
企微 WebSocket 真实对接 → 双平台消息测试 → 审批推送到 IM → 命令路由
```

### 阶段 2（1-2周）：Agent 进化

```
多轮对话 → Tool Use (function_call) → 子 Agent 编排 → Context 压缩
```

### 阶段 3（1周）：数据对接 + 安全

```
飞书多维表格 → Excel 智能解析 → HTTPS + 备份 → 测试框架
```

---

*V10 已经让系统"活"了起来 — Agent 能真正对话和自动工作。V11 的重点是让它在双平台上真正服务用户，并具备工具调用能力。*
