# 多角色用户体验报告与改进方案

> 测试环境: http://159.75.48.163:8000  
> 测试时间: 2026-04-08  
> 测试版本: V8.0.0

---

## 一、角色定义

| 角色 | 代表人物 | 权限级别 | 使用频率 | 核心诉求 |
|------|---------|---------|---------|---------|
| **老板** | 陈志远 | T1（全权限） | 每日 1-3 次 | 一眼看全局、快速审批、异常预警 |
| **部门经理** | 李明（电商）/ 周强（技术） | T2（限定范围） | 每日 3-5 次 | 管团队任务、看 KPI、辅导员工 |
| **一线员工** | 张小芳（Temu运营） | T3（仅IM） | 不使用后台 | 通过飞书/企微与 Agent 交互 |
| **HR/财务中台** | 钱婷（HR）/ 冯敏（财务） | T2 | 每周 2-3 次 | 考勤、薪酬、对账、报表 |
| **首次使用管理员** | — | T1 | 仅1次 | 初始化系统、配置团队 |

## 二、角色 1：老板（陈志远）视角

### 2.1 使用流程

```
登录 → 总览页（看统计） → 审批中心（处理待办） → 查看异常团队 → 查看某员工 KPI
```

### 2.2 体验记录

| 步骤 | 操作 | 结果 | 体验评分 |
|------|------|------|---------|
| 1 | 登录 | 正常，跳转总览 | ★★★★★ |
| 2 | 总览看统计 | 显示团队数/任务/审批数 | ★★★☆☆ |
| 3 | 点击审批中心 | 3条待审批，可批准/驳回 | ★★★★☆ |
| 4 | 批准奖金审批 | 302 重定向成功 | ★★★★☆ |
| 5 | 驳回考勤异常（填原因） | 302 成功 | ★★★★☆ |
| 6 | 查看电商团队详情 | 显示 KPI、成员、子Agent | ★★★☆☆ |
| 7 | 查看员工管理页 | 19人列表，可筛选 | ★★★★☆ |

### 2.3 痛点与改进

| # | 痛点 | 严重程度 | 改进方案 |
|---|------|---------|---------|
| B1 | **总览页数据不够"老板化"** — 只有基础统计，缺少：今日收入、本月利润、异常警报数、趋势图 | 高 | 增加「今日营收」「本月利润」「异常预警」统计卡片，接入 KPI 实际数据。增加简易趋势图（HTMX + Chart.js 或 SVG 火花图） |
| B2 | **审批缺少批量操作** — 3条审批要逐个点击查看再操作 | 中 | 审批列表页增加「全选→批量批准」按钮，对高可信度(A)+低优先级审批支持一键批量处理 |
| B3 | **从审批无法跳转到员工/任务/KPI详情** — 审批详情只展示 JSON，没有关联跳转链接 | 高 | 审批详情中的 employee、task、kpi_definition 等 ID 渲染为超链接，点击可直接跳到对应详情页 |
| B4 | **没有「老板专属仪表盘」** — 和普通管理员看到的完全一样 | 中 | 未来增加老板个性化首页：审批+预警+营收+排行，支持自定义卡片布局 |
| B5 | **审批后没有即时反馈** — 批准后 302 回列表，没有 toast 提示"操作成功" | 低 | 添加 Alpine.js toast 通知组件，POST 成功后显示"已批准/已驳回"提示 |

## 三、角色 2：部门经理（李明 — 电商经理）视角

### 3.1 使用流程

```
登录(T2) → 总览 → 团队管理 → 电商团队详情 → 任务管理(筛选本团队) → KPI → 创建新任务给员工
```

### 3.2 体验记录

| 步骤 | 操作 | 结果 | 体验评分 |
|------|------|------|---------|
| 1 | 登录（假设 T2 账号） | 正常 | ★★★★★ |
| 2 | 看总览 | 显示全公司数据（不是只看自己团队） | ★★★☆☆ |
| 3 | 点击团队管理 → 电商团队 | 正常，展示成员/KPI | ★★★★☆ |
| 4 | 任务管理，筛选电商团队 | 只看到电商的4条任务 | ★★★★☆ |
| 5 | 创建新任务给张小芳 | 表单填写→302 成功 | ★★★★☆ |
| 6 | 查看 KPI 管理 | 所有团队 KPI 都展示（应只看自己的） | ★★☆☆☆ |

### 3.3 痛点与改进

| # | 痛点 | 严重程度 | 改进方案 |
|---|------|---------|---------|
| M1 | **T2 用户看到全公司数据** — 总览页、KPI页、任务页默认展示所有团队 | 高 | T2 用户登录后自动按 team_id 过滤。需在 auth_middleware 中写入 `request.state.user_team_ids`，各页面查询时自动加条件 |
| M2 | **任务创建时需手动选团队** — 经理只管一个团队，不应每次选 | 中 | T2 用户创建任务/KPI时自动填充所属团队，隐藏团队选择下拉 |
| M3 | **没有「我的团队」快捷入口** — 经理进页面后要从6个团队中找自己的 | 中 | T2 用户的总览页直接展示自己团队的数据和快捷操作 |
| M4 | **员工管理缺少"辅导记录"** — 经理无法给员工添加辅导笔记 | 中 | 员工详情增加「辅导记录」tab，可添加文字记录和标签，关联到记忆系统 L2 层 |
| M5 | **无法查看员工的历史 KPI 成绩** — KPI 详情只有定义，没有按员工的打分记录 | 高 | 增加 KPI 评分记录页面：按员工+月份查看历史评分、等级、趋势 |

## 四、角色 3：一线员工（张小芳 — Temu 运营）视角

### 4.1 使用流程（IM 端）

```
飞书群里@机器人 → Agent 回复今日任务 → 提交日报 → 查看 KPI 进度 → 提出申诉
```

### 4.2 体验记录

| 步骤 | 操作 | 结果 | 体验评分 |
|------|------|------|---------|
| 1 | 飞书对话 | 需配置机器人后才能使用 | ★★☆☆☆ |
| 2 | 提交反馈 | 后台任务详情页可添加 | ★★★☆☆ |
| 3 | 查看 KPI | 无员工自助查看页 | ★☆☆☆☆ |

### 4.3 痛点与改进

| # | 痛点 | 严重程度 | 改进方案 |
|---|------|---------|---------|
| E1 | **员工没有自助门户** — 无法自己查看任务、KPI、工资 | 高 | 后续增加 T3 员工自助页面（只读）：我的任务、我的 KPI、我的薪酬预估、提交申诉入口 |
| E2 | **飞书机器人未配置** — Agent 无法收发消息 | 高 | 需在飞书开放平台完成：1.事件订阅配置 2.IP白名单 3.权限开通。是系统外配置工作 |
| E3 | **任务反馈只支持文本** — 员工可能需要上传截图、表格 | 中 | task_feedback 增加文件上传功能，支持图片和 Excel。表单 enctype="multipart/form-data" |
| E4 | **没有工作日报模板** — 员工不知道要提交什么内容 | 中 | 为每个团队配置日报/周报模板，员工提交时按模板填写 |

## 五、角色 4：HR/财务中台（冯敏 — 财务主管）视角

### 5.1 使用流程

```
登录 → 财务团队详情 → 任务管理(3月对账任务) → 上传 ERP 导出表格 → 查看对账结果
```

### 5.2 痛点与改进

| # | 痛点 | 严重程度 | 改进方案 |
|---|------|---------|---------|
| F1 | **无文件上传功能** — 财务需要上传 ERP 导出的 Excel，目前只能通过飞书发送 | 高 | 增加文件上传入口（知识库/任务附件），调用 file_parser skill 解析 Excel 数据 |
| F2 | **对账流程无可视化** — 对账是复杂流程（匹配订单→计算利润→分运营汇总），但后台无展示 | 中 | 后续开发对账专用页面：上传两份表格 → AI 自动匹配 → 差异标记 → 生成报表 |
| F3 | **薪酬计算无页面** — reward_calculations 表有数据但没有前端页面 | 中 | 增加「薪酬计算」页面：按月查看每个员工的 KPI→奖金→提成→总薪酬 |

```
访问 /wizard/step1 → 逐步配置 → 创建团队 → 添加员工 → 配置机器人 → 完成
```

### 6.2 体验记录

| 步骤 | 操作 | 结果 | 体验评分 |
|------|------|------|---------|
| 1 | 访问 /wizard/step1 | 200 正常（无需登录） | ★★★★★ |

### 6.3 痛点与改进

| # | 痛点 | 严重程度 | 改进方案 |
|---|------|---------|---------|
| W1 | **向导没有进度条** — 7步不知道当前到第几步 | 低 | 顶部增加 step indicator（1/7 → 2/7 ... ） |
| W2 | **向导完成后没有自动跳转** — 不知道去哪里 | 中 | step7 完成后自动跳转到总览页或登录页 |
| W3 | **向导无法跳过步骤** — 如果已有模型配置，不需要重新填 | 低 | 增加「跳过此步」按钮 |
