## 1. 系统概述

千方百计AI 是一个 **AI 驱动的企业管理操作系统**。核心理念是：

- **系统 = 手机**：底层操作系统提供通用能力（模型、记忆、审批、通知等）
- **Agent 团队 = App**：每个业务团队是一个独立的 "App"，配置自己的 AI 助手、KPI、任务流程
- **半自动管理**：AI 自动感知 → 生成建议 → 推送审批 → 老板/主管批准 → 自动执行

### 当前测试数据（千帆海公司）

| 维度 | 数据量 | 说明 |
|------|--------|------|
| 团队 | 6 个 | 跨境电商、ERP开发、ERP销售、POD工厂、HR中台、财务中台 |
| 员工 | 19 人 | 含1个老板、5个经理、13个员工 |
| 任务 | 12 条 | 覆盖各团队的真实业务场景 |
| KPI | 10 项 | 月销售额、ROAS、Sprint完成率、良品率等 |
| 审批 | 3 条 | 奖金审批、紧急任务分配、考勤异常 |
| 客户 | 3 个 | ERP销售团队的客户档案 |
| 知识库 | 5 篇 | 运营SOP、签约流程、质检标准等 |
| 模型 | 2 个 | DeepSeek Chat + DeepSeek Reasoner |

## 4. 团队管理

**路径**: `/teams`  
**作用**: 管理所有 Agent 团队

### 团队列表页

- 展示所有团队卡片，每个卡片显示：
  - 团队名称和部门

## 6. 任务管理

**路径**: `/tasks`  
**作用**: 查看和管理所有团队的任务

### 任务列表

- **筛选**：按团队、按状态（待分配/已派发/进行中/已提交/已评分/已完成/已超时）
- **排序**：按截止时间、创建时间
- 每条任务显示：负责人、所属团队、状态标签、截止时间

### 任务详情（点击任务进入）

| 区域 | 内容 |
|------|------|
| 基本信息 | 标题、描述、负责人、创建时间 |
| 时间线 | 派发时间 → 截止时间 → 完成时间 |
| 评分 | 综合分 = 时效性 × 权重 + 质量 × 权重 + 复杂度权重 |
| 反馈记录 | 员工提交的反馈列表（文本/文件/图片） |
| 催办记录 | 系统自动催办的历史 |

### 手动创建任务

在任务列表页点击「+ 新建任务」：
1. 选择目标团队
2. 选择负责人（该团队下的员工）
3. 填写标题和描述
4. 设置截止时间
5. 提交

## 7. 升级处理（三级上报）

**路径**: `/escalations`  
**作用**: 查看任务催办和三级上报记录

### 机制说明

当任务接近或超过截止时间，系统自动触发催办：

1. **第一级**（如30分钟后）：提醒负责员工
2. **第二级**（如60分钟后）：通知直属经理
3. **第三级**（如120分钟后）：上报老板

每个团队的催办间隔可单独配置。

### 页面内容

- 催办列表：按任务分组显示
- 催办时间线：点击某条催办记录查看完整上报链路
- 状态：已发送 / 已响应（标记经理或老板响应的时间）

## 8. 申诉中心

**路径**: `/disputes`  
**作用**: 员工对 AI 评分、奖惩结果提出异议

### 申诉流程

```
员工发起 → 证据收集 → 裁决中 → 已解决/已推翻
```

### 申诉详情

- 原始数据：AI 当初的评分和依据
- 员工理由：员工提交的申诉说明
- 证据列表：支持申诉的附件
- 裁决结果：老板/主管的最终判定
- 规则修正建议：如果申诉成立，建议修改的规则

## 10. 知识库

**路径**: `/knowledge`  
**作用**: 管理 Agent 团队可引用的知识文档

### 知识分类

- **公司级**：所有团队可引用（如员工手册）
- **部门级**：仅指定部门的团队可引用（如电商部的运营 SOP）

### 知识状态

- `active`：已生效，Agent 可引用
- `candidate`：候选（由做梦引擎提取，待审核）
- `archived`：已归档

### 操作

- 查看知识列表和内容
- 按分类和部门筛选
- 查看知识待审核列表（`/knowledge/pending`）

## 15. 常见问题

### Q: 忘记密码怎么办？

当前版本暂不支持自助找回密码。需要管理员通过服务器命令重置：

```bash
cd /home/ubuntu/qfbj
./venv/bin/python -c "
from app.core.database import Database
from app.dashboard.auth import hash_password
db = Database.get_instance('data/qfbj.db')
db.update('dashboard_users', 'USER_ID', {'password_hash': hash_password('新密码')})
"
```

### Q: 如何给团队配置飞书机器人？

1. 进入团队详情页 → 机器人 Tab
2. 填写飞书开放平台的 App ID 和 App Secret
3. 在飞书开放平台配置事件订阅 URL：`http://159.75.48.163:8000/webhook/feishu`
4. 保存并启用

### Q: 如何新增一个 Agent 团队？

1. 进入「团队管理」列表页
2. 点击「+ 创建团队」
3. 填写：团队名称、部门、System Prompt
4. 选择主模型和备用模型
5. 选择自动化档位（创业/中层管理/流程驱动）
6. 保存后配置子Agent、KPI、技能

### Q: 影子模式是什么？

新团队默认运行在「影子模式」：AI 正常工作但不执行任何动作，仅记录"如果执行会怎样"。
运行 7-14 天后，验证数据准确性和建议质量，再切换到正式模式。

### Q: 自动化 4 档分别是什么？

| 档位 | 含义 |
|------|------|
| L1 仅提醒 | 告诉老板/主管，不生成动作 |
| L2 建议执行 | 生成建议，等审批 |
| L3 自动执行并报备 | 先做，再推送结果 |
| L4 全自动闭环 | 完全自动，不打扰 |

### Q: 可信度 A/B/C 怎么理解？

| 等级 | 含义 | 处理方式 |
|------|------|---------|
| A 高可信 | AI 高度确定 | 可配置为自动执行 |
| B 中可信 | AI 中等确定 | 建议审批后执行 |
| C 低可信 | AI 不确定 | 仅提示，不进闭环 |
