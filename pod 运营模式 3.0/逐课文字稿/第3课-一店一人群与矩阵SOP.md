# 第 3 课：一店一人群与矩阵 SOP

## 建议时长

15-22 分钟

## 对应 PPT

第 9-12 页

## 课程目标

让学员从“找到一个方向”走到“完成一批可测试款式的规划”。

## 可直接录制的文字稿

欢迎来到第三课。

前面两课，我们解决了两个问题：第一，为什么不能泛铺；第二，什么样的人群值得做。

这一课，我们进入真正的执行层，也就是：一个方向确定以后，到底怎么落到店铺和上架动作里。

第一条规则非常重要，也是整个体系里必须死守的一条纪律：一个店铺，只做一个人群方向。

请注意，这句话不是建议，而是经营纪律。

不是说这个店今天放宠物，明天放护士，后天再放妈妈赛道。也不是先把店开出来，再慢慢想里面放什么。

正确顺序一定是反过来的。先选人群，再开店绑定这个人群，然后在这个人群内部测试不同表达。

所以一个店铺，本质上不是一个货架，而是一个人群资产池。

比如这个店如果是做 `Golden Retriever Mom` 的，那这个店里就应该全部围绕这类人群展开。搞笑、自豪、礼物、日常、户外，这些都可以测，但人群不能乱。

为什么不能混？因为一旦混赛道，平台不知道你到底服务谁，买家也不会觉得这个店是为自己开的。你会重新回到泛铺状态。

接下来，确定人群之后，我们要做的不是“随便出几款”，而是做矩阵。

矩阵的意思，是围绕同一个人群，从四个维度系统展开。

第一个维度是情绪。比如搞笑、自嘲、温馨、自豪。

第二个维度是风格。比如极简文字、卡通插画、手写字体、梗图风。

第三个维度是语言。比如英文、本地语言、双语混搭。

第四个维度是场景。比如日常穿、生日礼物、工作场景、节日纪念。

请记住，矩阵的目的不是把表格填满，而是系统化覆盖同一人群可能下单的表达。

比如我们拿 `Night Shift Nurse PH` 来举例。

同样是夜班护士，你可以做自嘲路线，比如“没睡没钱但还是护士”；也可以做自豪路线，比如“Filipino Nurse, Saving Lives Worldwide”；也可以做礼物路线，送给护士同事；也可以做工作吐槽路线。

这些都还是同一个人群，只是表达不同。

接下来，从矩阵表走到款式清单，每个款式都要有编号、有情绪、有风格、有语言、有场景，最后再形成具体文案和设计方向。

到这里你会发现，真正的测试不是“乱试很多人群”，而是在一个人群里有方法地测很多表达。

最后讲上架节奏。

首批测试不要一天全上完。建议分 2 到 3 天上，每天一部分。这样每一批都更有机会吃到平台的新品流量窗口。

而且每一条链接都要记录：属于哪个赛道、什么风格、什么语言、哪天上的。因为后面你要回看数据，如果没有这些记录，你根本不知道是哪个表达在起作用。

所以这一课的核心动作有三个：先把店和人群绑定，再用四维矩阵展开，最后把矩阵变成一批可追踪、可测试、可复盘的链接。

## 配图或指导图建议

1. 店铺架构图：一个店 -> 一个人群 -> 多个表达方向。
2. 四维矩阵空白模板。
3. `Night Shift Nurse PH` 或 `Golden Retriever Mom` 实际矩阵示例。
4. 上架节奏时间轴：第 1 天、第 2 天、第 3 天分批上。
5. 链接记录表样例。

## 演示方式

1. 最适合“边讲边填表”。
2. 可以在屏幕上现场打开表格，逐格填写一个真实赛道。
3. 如果是录播课，建议加入“从矩阵到款式清单”的动画箭头。
4. 讲师可以手写框出四个维度，增强记忆点。
