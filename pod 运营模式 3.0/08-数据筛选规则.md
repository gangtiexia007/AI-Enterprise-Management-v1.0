# 数据筛选规则

> 款式的生死不靠感觉，靠数据。本文档定义了从上架到淘汰/放大的完整判断标准。

---

## 核心原则

1. **每个款式都有观察期**：不是上架了就不管了，也不是上架两天没单就急着下架
2. **分阶段看不同指标**：前 3 天看曝光和点击，7 天看出单，14 天做最终判断
3. **数据驱动决策**：所有保留/淘汰/放大的决定都基于数据，不基于"我觉得这个设计好看"
4. **快速迭代**：淘汰不是失败，是在帮你缩小范围——每淘汰一批，离爆款就更近一步

---

## 有效链接标准（初期简化版）

> **使用场景**：团队数据能力尚不足以跑下方 S/A/B/C 四级筛选时，先用本节的「有效链接标准」做最简判断。两套标准并存，随团队能力成长逐步切换到完整四级体系。


| 分类               | 定义                                     | 处理                                  |
| ---------------- | -------------------------------------- | ----------------------------------- |
| **起单信号**         | 14 天内出 1 单                             | 值得继续观察，不急于判断                        |
| **有效链接**         | 14 天内至少 2 单，且订单分布在 2 天及以上（不是同一天偶发冲出来的） | 初步稳定，纳入运营考核的「有效链接数」                 |
| **无效链接**         | 30 天 0 单                               | 必须下架，不再投入精力                         |
| **量起来（进入放大观察线）** | 满足任一：连续 7 天累计 10+ 单，或连续 3 天都有单         | 进入这个阶段后，才有意义去重点看退货、差评、售后            |
| **问题爆款**         | 高销量但高差评 / 高退货 / 高售后                    | 先停放大 → 查根因 → 能修就修 → 修不动就停。高销量不等于好产品 |


### 关于退货、差评、利润

- **不混入** 14 天初筛标准
- 初期样本小（1-2 单），看退货率和差评率容易误判
- 属于「量起来以后」的后续层判断

### 与完整四级体系的关系

本节定义的「有效链接」标准是**入门版筛选**，聚焦在「这条链接到底能不能卖」。当团队能定期采集曝光、点击、收藏等过程数据后，应逐步启用下方的四个核心指标与 S/A/B/C 分级体系，做更精细的款式管理。

---

## 四个核心指标


| 指标         | 计算方式                 | 反映什么       | 出问题时说明什么               |
| ---------- | -------------------- | ---------- | ---------------------- |
| **点击率**    | 点击量 ÷ 曝光量 × 100%     | 主图/标题是否吸引人 | 点击率低 = 主图或标题有问题        |
| **收藏/加购率** | 收藏(加购)量 ÷ 点击量 × 100% | 买家是否有购买意愿  | 有点击无收藏 = 赛道不够精准或设计没有共鸣 |
| **转化率**    | 出单量 ÷ 点击量 × 100%     | 是否真的产生购买   | 有收藏无转化 = 价格或产品链接有问题    |
| **投产比**    | 销售额 ÷ 总成本（含广告）       | 是否值得继续投入   | 投产比 < 1 = 亏钱           |


### 各平台的参考基准值

> 以下为参考值，实际基准需要根据自己的数据积累调整。


| 指标     | TikTok 菲律宾 | Shopee 菲律宾 | Temu半托管 | Temu全托管 |
| ------ | ---------- | ---------- | ------- | ------- |
| 点击率合格线 | ≥ 3%       | ≥ 2%       | ≥ 2.5%  | ≥ 3%    |
| 收藏率合格线 | ≥ 2%       | ≥ 3%       | ≥ 2%    | —（看加购）  |
| 转化率合格线 | ≥ 1.5%     | ≥ 1%       | ≥ 1.5%  | ≥ 2%    |


**重要**：数据量小时百分比波动很大。曝光样本太少时的点击率不具备判断意义，需要积累足够的曝光量后再看比率（具体门槛以各平台后台实际数据为准）。

## 款式分类体系

每个款式根据数据表现归入以下四类：


| 分类           | 定义              | 后续动作                 |
| ------------ | --------------- | -------------------- |
| **S 级（爆款）**  | 持续出单，数据全面优秀     | 立即做变体 + 跨平台分发 + 广告放量 |
| **A 级（潜力款）** | 有出单但不稳定，或数据部分优秀 | 优化产品链接后继续观察          |
| **B 级（待优化）** | 有点击/收藏但未出单      | 针对性优化后再给 7 天         |
| **C 级（淘汰）**  | 无反应             | 下架或放弃                |

## 分时间节点的筛选流程

### 第 1-3 天：看曝光和点击

这个阶段只看两个东西：平台给不给曝光，买家点不点进来。


| 情况           | 判断                   | 动作                         |
| ------------ | -------------------- | -------------------------- |
| 无曝光（0 或极低）   | 标题/标签/类目有问题，平台不知道推给谁 | 修改标题和标签，添加更精准的关键词，检查类目是否选对 |
| 有曝光，点击率低于合格线 | 主图不吸引人               | 换主图（更清晰的文案展示、更好的产品效果图）     |
| 有曝光，点击率达标    | 通过第一关                | 继续观察，等收藏和出单数据              |


### 第 4-7 天：看收藏和出单


| 情况                | 判断              | 动作                                         |
| ----------------- | --------------- | ------------------------------------------ |
| 点击率达标 + 有收藏 + 有出单 | **S/A 级候选**     | 标记为放大候选，**由负责该链接的运营**做变体（模式 D 下无单独「铺货组」岗位） |
| 点击率达标 + 有收藏 + 无出单 | **B 级**：有兴趣但没买  | 检查价格（是否太高）、检查产品链接详情（是否不够有说服力）、检查竞品价格       |
| 点击率达标 + 无收藏 + 无出单 | 设计有视觉吸引力但没有情感共鸣 | 可能赛道不够精准。保留观察到第 14 天，在**三问周报或周会**与主管复盘选品方向 |
| 点击率不达标 + 已换过主图    | 设计本身没有吸引力       | **C 级**：淘汰                                 |


### 第 7-14 天：最终判断


| 情况                  | 最终分类    | 动作                                  |
| ------------------- | ------- | ----------------------------------- |
| 持续出单（7 天内 ≥ 3 单）    | **S 级** | 立即进入放大期：做 5-10 个变体，围绕人群做深，跨平台分发      |
| 出过单但不稳定（7 天内 1-2 单） | **A 级** | 优化后继续观察一周。仍有单 → 升为 S 级；没单了 → 降为 B 级 |
| 有收藏/加购但始终没出单        | **B 级** | 调低价格或做产品链接大改，给最后 7 天。仍无单 → 降为 C 级   |
| 14 天全程无反应           | **C 级** | 淘汰。下架或不再关注。                         |

## 判断流程图

```
上架第 1 天
    │
    ├── 3 天后：有曝光吗？
    │       ├── 没有 → 改标题/标签/类目 → 重新计算 3 天
    │       └── 有 → 点击率达标吗？
    │               ├── 不达标 → 换主图 → 再看 3 天
    │               └── 达标 → 继续
    │
    ├── 7 天后：出单了吗？
    │       ├── 有出单 → S/A 级候选 → 准备放大
    │       ├── 有收藏无单 → B 级 → 优化价格/产品链接
    │       └── 无收藏无单 → 观察到第 14 天
    │
    └── 14 天后：最终判断
            ├── 持续出单 → S 级 → 全力放大
            ├── 偶尔出单 → A 级 → 继续优化观察
            ├── 有收藏无单 → 最后一次优化机会
            └── 全程无反应 → C 级 → 淘汰
```

## 优化操作手册

当款式被标记为 B 级（待优化）时，按以下顺序排查和修复：

### 优化优先级


| 优先级 | 优化项    | 什么时候做  | 怎么做                          |
| --- | ------ | ------ | ---------------------------- |
| 1   | 主图     | 点击率低   | 换更清晰的产品效果图、让文案在缩略图中可读、尝试不同角度 |
| 2   | 标题     | 曝光低    | 加入更精准的长尾关键词、参考同赛道竞品标题        |
| 3   | 价格     | 有收藏无单  | 对比竞品定价，尝试降价 10-15%           |
| 4   | 标签/关键词 | 曝光低    | 补充更多相关关键词，覆盖买家搜索习惯           |
| 5   | 详情页    | 有点击无收藏 | 加更多场景图、添加尺码说明、突出情感卖点         |


### 优化的纪律

- 一次只改一个变量：不要同时换图、改标题、调价格——否则不知道是哪个改动起了作用
- 改完后重新计算观察期：从修改日起重新算 3-7 天
- 最多优化两轮：如果优化两次后仍无反应，直接淘汰

## 赛道级别的判断

除了单个款式的筛选，还需要在赛道级别做判断：

### 赛道健康度评估


| 指标                   | 健康      | 警告     | 放弃     |
| -------------------- | ------- | ------ | ------ |
| 首批测试款中的 S+A 级比例      | ≥ 15%   | 5-15%  | < 5%   |
| 7 天内总出单量             | ≥ 5 单   | 1-4 单  | 0 单    |
| 整体点击率                | ≥ 平台合格线 | 略低于合格线 | 远低于合格线 |


### 赛道级别的决策


| 赛道状态 | 动作                            |
| ---- | ----------------------------- |
| 健康   | 进入放大期，方向确认后围绕人群做深          |
| 警告   | 补一批新设计（换角度/换表达），再观察一个周期 |
| 放弃   | 停止该赛道，资源转向下一个                 |
