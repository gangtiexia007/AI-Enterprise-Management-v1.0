# 团队分工与考核指标

> **1 名主管 + N 名运营。**  
> **阶段一（当前）：模式 D —— 全员独立作战**：每人负责自己的店铺与链接；Temu / TikTok / Shopee **同一产品多平台上架**（工具自动同步），**不按平台分组**；考核以 **有效链接数、爆款数、选品命中率** 为主，**主管汇总数据、透明排名**；不以「日均上架量」为正向 KPI。  
> **薪酬、绩效分、提成解锁规则**见 `10-运营绩效与提成制度.md`。

## 二、模式 D（独立作战 + 有效链接 + 透明排名）


| 要素       | 说明                                                       |
| -------- | -------------------------------------------------------- |
| **独立作战** | 每人从选品、作图、上架到看数据，**全流程自负**；主管不分配「你今天上什么类目」。               |
| **全平台**  | 同一设计在 Temu / TikTok / Shopee 同步上架；**不**设「只负责 TikTok 的人」。 |
| **有效链接** | 定义见 `08`；与 `10` 考核口径一致。                                   |
| **透明排名** | 主管按周汇总各运营有效链接、爆款、命中率（及毛利结果），**全员可见排名逻辑**（具体是否公开名单由公司定）。  |
| **指挥棒**  | 有效链接与爆款；上架量是手段，**不作为正向 KPI 主权重**。过渡期保底动作：每天至少上架 50 条 + 每天 30 分钟回看近 7 天出单情况并思考共性。 |

## 四、主管职责（阶段一）


| 职责       | 具体内容                                      |
| -------- | ----------------------------------------- |
| **收周报**  | 周一收齐三问周报，追问糊弄                             |
| **导数据**  | 周二从 ERP 等导出订单，按人拆分 **有效链接、爆款、命中率**（可借助工具） |
| **透明排名** | 填汇总表交老板（见下方「老板视角」）                        |
| **店铺归属** | 确保每店、每批链接**可归因到人**，无主链接不参与考核              |
| **周会**   | 复盘数据、同步公司规则；**不**代替运营做选品决策                |
| **红线**   | 重大事故（封店、价格错误等）按 `10` 与制度处理                |


**不再默认承担**：给研究组 / 铺货组派流水线任务（阶段一没有这两组岗位）。

### 老板每周看什么

- 主管交的 **汇总表**（有效链接、爆款、命中率排名）
- 有效链接数的 **变化趋势**（在涨还是在跌）
- 有没有人开始产出 **新的爆款方向**
- 翻一翻运营的 **三问周报内容**，看谁在思考、谁在糊弄

## 五、运营职责（阶段一）


| 职责        | 具体内容                                       |
| --------- | ------------------------------------------ |
| **店铺**    | 只做**归属到自己名下**的店铺；新店方向、人群定位自己跟主管、老板对齐（规则见 `02`）|
| **选品与上架** | 自选方向；可参考 `03`/`04` 赛道清单与 `05` 矩阵流程，**非强制** |
| **全平台**   | 一稿多平台发布；各平台微调标题/主图可自己做                     |
| **看数据**   | 按 `08` 做款式分级、优化、淘汰/放大                      |
| **周报**    | 周一交三问周报（见下节）                               |

## 六、三问周报机制

每周一，所有运营向主管提交一段文字（不超过 300 字），回答：

1. 上周我上了多少条链接？其中哪些出单了？
2. 哪条卖得最好？我觉得它为什么能卖？
3. 这周我准备往什么方向选品？为什么？

**提交方式**：微信 / 飞书 / 钉钉文字即可。  

**主管**：收齐、防糊弄、摘要给老板。  

**老板**：看有效链接变化、爆款苗头、谁在思考谁在糊弄。

## 七、阶段二：赛道小组（跑出成绩之后）

当某人持续跑出有效链接与爆款，可 **围绕其建「赛道小组」**：


| 角色     | 说明                                                    |
| ------ | ----------------------------------------------------- |
| **组长** | 一般为数据验证过的标杆；定赛道方向、带方法                                 |
| **组员** | 1–2 人协助放大执行（上架、变体），**师傅带徒弟**，不必一上来就拆成「研究 / 铺货 / 数据」三岗 |
| **提成** | 组长个人提成 + **小组管理提成**，见 `10` 运营组长条款                     |


小组成熟、人数 **≥15 运营** 等条件满足时，再考虑是否引入 **附录 A 三组流水线**。

### 如何发现与提炼标杆

- 对有效链接与爆款排名持续靠前的运营，**提炼其选品方法**。
- 不是让他讲课，而是 **具体问**：你选图的时候看什么、不选什么、在哪里找图、怎么判断一个方向值不值得做。
- 把这些做法整理出来，作为其他运营的选品参考（可纳入 `01` 案例或内部分享）。

## 八、月度复盘与人员调整

### 月度复盘（每月初）

- 拉出整月数据，与上月对比
- 每个运营的 **有效链接数、爆款数、命中率** 排名

### 人员调整规则


| 情况                        | 处理                 |
| ------------------------- | ------------------ |
| 连续 2 个月有效链接数垫底            | 调岗或淘汰              |
| 连续 2 个月三问周报糊弄（被主管追问后仍无改善） | 警告一次，第三个月不改就淘汰     |
| 有效链接数排名第一                 | 当月额外奖金（金额见 `10`）   |
| 产出 50+ 爆款                 | 每个爆款单独奖（金额见 `10`）  |


### 团队规模评估

- 如果数据证明 3–4 个人能产出跟 7–8 个人一样的有效链接数，考虑缩减团队
- 省下来的人力成本可以转为爆款奖金，激励留下来的人

### 绩效与薪酬

薪酬、绩效分档、阶梯提成、专项奖与团队管理提成等，见 **`10-运营绩效与提成制度.md`**。

**原则摘要**：

- 薪资结构：底薪 + 绩效（KPI）+ 阶梯提成 + 专项奖 + 团队奖金。  
- KPI：有效链接、爆款、命中率；毛利为结果校验；**解锁提成**可用「毛利门槛 **或** 有效链接门槛」二选一（以盖章版为准）。  
- 淘汰：连续多月有效链接垫底或毛利不达标等，见 `10`。

## 附录 A：阶段三可选——三组流水线（规模化后参考）

> **适用时机**：团队规模较大、单赛道需要分工提效时；**不是当前默认模式**。  
> 下列内容为早期「选品研究组 / 矩阵铺货组 / 数据优化组」协作说明，保留备查。

### A.1 架构示意

```
                    主管（1 人）
                  ┌────┼────┐
          选品研究组   矩阵铺货组   数据优化组
          (1-2 人)    (3-4 人)    (1-2 人)
```

三个组围绕：**找到细分赛道 → 批量出设计 → 数据筛款 → 放大出单**。

### A.2 选品研究组（摘录）


| 职责           | 内容                                               |
| ------------ | ------------------------------------------------ |
| 赛道发掘、拆分、竞品分析 | 输出文案方向给铺货组                                       |
| 渠道           | TikTok、Facebook Groups、Shopee/Temu、Etsy、Reddit 等 |


### A.3 矩阵铺货组（摘录）


| 职责         | 内容                           |
| ---------- | ---------------------------- |
| 矩阵展开、设计、上架 | 按 `05` 执行                    |
| 产能参考       | 测试期文字款约 15–20 款/人/日 等（以实际为准） |


### A.4 数据优化组（摘录）


| 职责                | 内容        |
| ----------------- | --------- |
| 采集数据、分级、通知变体、链接优化 | 按 `08` 执行 |


### A.5 协作流程与周节奏（摘录）

协作节点：研究 → 铺货 → 优化 → 反馈研究；周一会、周五筛款等，与旧版「流水线」文档一致，此处不重复展开。

## 附录 B：从「各自铺货」过渡到模式 D（建议节奏）

1. **第 1 周**：全员会宣布新考核规则（有效链接 + 爆款取代铺量 KPI）；店铺全部归属到人；启动三问周报。
2. **第 2–4 周**：主管按周出排名表；运营按 `08` 自查链接；保持保底上架 + 每日回看出单。
3. **第 2 个月起**：执行月度复盘与人员调整（见第八节）；数据上出现标杆则启动「赛道小组」讨论。
