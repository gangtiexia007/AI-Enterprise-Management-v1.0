# 运营绩效与提成制度

> 本文档由《千帆海运营绩效提成》整理为 Markdown，并与当前运营战略对齐：**全员独立作战 + 以有效链接与爆款为指挥棒 + 毛利为结果校验**；后续跑出成绩的同事可带「赛道小组」，再逐步启用小组管理提成。  
> **说明**：涉及底薪档位、提成比例、具体金额以公司财务与 HR 盖章版为准；本文件用于运营团队理解与执行对齐。

**与其他文档的口径**：`07` 阶段一组织、周回收与月度复盘、阶段二赛道小组，`08` 有效链接定义，共用同一套「有效链接 + 爆款」逻辑；**发钱与绩效分**以本文 + 盖章制度为准。

---

## 一、毛利计算（与薪酬挂钩的基础）

```
毛利 =（销售额 × 70%）− 广告费 −（销量 × 单件成本）
```

- 「销售额 × 70%」为**回款预估**口径，便于快速核算绩效（非最终财务毛利）。
- **单件成本**：拿货价 + 运费（若有）。
- 各岗位提成、阶梯奖仍**以毛利或约定口径的销售结果为基数**，按公司当期制度执行。

---

## 二、薪资结构（总框架，保持不变）

采用 **「底薪 + 绩效（KPI）+ 阶梯提成 + 专项奖 + 团队奖金」** 结构。


| 模块      | 作用                                |
| ------- | --------------------------------- |
| 底薪      | 与职级挂钩                             |
| 绩效（KPI） | 与**过程与质量**挂钩（有效链接、爆款、命中率、主管交办事项等） |
| 阶梯提成    | 与**经营结果**挂钩（通常按毛利/销售额分档）          |
| 专项奖     | **有效链接 / 爆款 / 规模里程碑**（见下文「专项奖」）   |
| 团队奖金    | 主管、赛道组长等管理角色适用                    |


---

## 三、薪资与晋升路径

```
C3（运营助理）→ C2（初级运营）→ C1（中级运营）→ B3（高级运营）
→ B2（运营组长）→ B1（运营主管储备）→ A2（运营主管）→ A1（运营总监储备）→ S（运营总监）
```

### 晋升流程（原则）

1. 提名：员工自荐 / 直属上级提名
2. 资质审核：HR 核查任职时长、绩效与业绩记录
3. 评估：基层岗（技能考核 + 业绩数据）；管理岗（答辩 + 团队成果）
4. 公示：拟晋升名单公示 3 个工作日
5. 正式晋升：同步调整薪资、提成与岗位职责

### 动态调整

- **降级**：连续 2 个月绩效低于 70 分，或连续 2 个月未达到业绩要求 → 降 1 级（以 HR 制度为准）。

## 四、绩效分发放规则（分数档）

绩效分数按岗位权重折算后：


| 绩效分            | 绩效奖金发放比例（示例，以公司制度为准） |
| -------------- | -------------------- |
| ≥ 80 分         | 全额发放                 |
| 60–80 分        | 按比例发放（如 50%）         |
| 40–60 分        | 按比例发放（如 30%）         |
| 高于 0 且不高于 40 分 | 扣除该部分绩效              |
| 具体档位           | **以 HR 最新规定为准**      |

## 五、运营组员 KPI（与「独立作战 + 有效链接」对齐）

### 5.1 核心任务表述（替代原「疯狂铺货」）

**原制度表述侧重铺量；现统一为：**

- **高效上新**：在保障链接质量的前提下完成上新与优化（上架量是手段，不是考核目的）。  
- **有效出单**：提升 **有效链接数**、**爆款数**，提升 **选品命中率**。  
- **Listing 优化**：主图、标题、价格等按数据反馈迭代（参见 `08-数据筛选规则.md`）。

### 5.2 KPI 建议权重方向（由主管在月度表中落地）


| 维度            | 说明                                        | 备注     |
| ------------- | ----------------------------------------- | ------ |
| **有效链接数**     | 定义见 `08-数据筛选规则.md`（如：14 天内 ≥2 单且分布在 ≥2 天） | 主过程指标  |
| **爆款数**       | 如：30 天内 50 单以上的链接数                        | 进阶结果指标 |
| **选品命中率**     | 有效链接数 ÷ 周期内总上架数（或公司约定分母）                  | 效率与判断力 |
| **毛利额 / 销售额** | 与公司提成阶梯、成本覆盖挂钩                            | 结果校验   |
| **制度执行**      | 三问周报提交、数据真实性、重大事故（封店、价格错误等）               | 红线项    |


> **不再单独考核「每日上架条数」作为正向 KPI**；若保留「保底上架」仅作为**过渡期劳动纪律或底线动作**，不计入绩效加分主力。

### 5.3 提成与专项奖解锁条件（「或」规则）

原制度常见表述为：**个人月毛利达到一定门槛后，方可享受提成与部分专项奖。**

为避免「命中率高但单量小」的同事长期拿不到激励，建议执行 **二选一（或）**（具体阈值由财务与老板确认后写入制度）：

- **路径 A**：月毛利 ≥ **公司设定门槛**（如原稿中的 20,000 元级别，以财务为准）  
- **路径 B**：当月 **新增有效链接数 ≥ 公司设定条数**（试跑 1–2 个月后根据数据校准）

满足 **A 或 B** 之一，即可按制度参与 **阶梯提成与专项奖** 核算（与 HR 最终条款一致）。

### 5.4 专项奖（在原「单量专项奖」基础上对齐战略）

原制度示例包含「月销破一定件数给予额外奖励」。为减少「无效铺量」激励，建议：


| 类型            | 思路                   | 说明                                     |
| ------------- | -------------------- | -------------------------------------- |
| **有效链接里程碑奖**  | 当月新增有效链接达到约定档        | 替代或并行于纯件数奖                             |
| **爆款专项奖**     | 当月产生约定标准的爆款（如 50+ 单） | 与 `07` 月度复盘中「爆款单独奖」一致                   |
| **规模奖（可选保留）** | 月销件数达到很高档位           | 仅作为**规模已起来后的加码**，且不以牺牲命中率为代价；是否保留由公司决定 |

## 六、运营组长（赛道组长）激励

对应原制度中的 **「运营组长」**；与业务规划一致时，即 **跑出成绩后组建的「赛道小组」负责人**。


| 部分       | 说明                                                                           |
| -------- | ---------------------------------------------------------------------------- |
| **个人部分** | 与运营组员相同规则，按个人账号/店铺独立核算                                                       |
| **管理提成** | 按小组业绩（如小组毛利、小组销售额等）× **约定比例**；原 PDF 示例曾出现「团队部分按团队规模与提成比例核算」，**具体比例以公司盖章版为准** |


**职责对齐（摘要）**：带教新人、选品方向把控、承接小组目标、任务分配、参与新人招聘与评估（与原 PDF 一致，可与 `07` 中组长职责合并表述）。

## 八、年终奖励（原则摘录）

常见条件包括：

- 入职满 12 个月，或连续 3 个月达到初级运营以上等。  
- 与公司当年盈利、团队总毛利等挂钩，分档给予 **13 薪 / 15 薪 / 18 薪 / 24 薪** 等（原 PDF 按「运营团队人均毛利 × 人数 × 12」等区间描述）。

**具体公式与当年是否执行，以当年公司公布为准。**

## 九、优胜劣汰与试用期（与有效链接制度对齐）

原制度强调效率与淘汰机制，保留精神，**指标建议改为可数据化核对**：

### 9.1 试用期（示例，需 HR 确认）


| 阶段     | 原 PDF 侧重         | 建议对齐后                                                               |
| ------ | ---------------- | ------------------------------------------------------------------- |
| 第 1 个月 | 熟练软件、日均上架达标、月出单量 | **熟练工具与流程** + **完成保底动作**（如每日有上新、每日回看出单、提交周报）+ **最低有效出单或毛利底线**（由公司定） |
| 第 2 个月 | 月毛利门槛            | **月毛利** 或 **有效链接数** 达到试用转正线                                         |


### 9.2 正式员工观察与末位


| 原 PDF 表述                 | 建议对齐                                    |
| ------------------------ | --------------------------------------- |
| 连续 2 个月个人毛利低于一定水平 → 观察名单 | 可增加 **「有效链接排名持续垫底」** 作为并列触发条件之一         |
| 第 3 个月未改善 → 降级或劝退        | 与 `07` 月度复盘中「连续 2 月垫底调岗/淘汰」统一由 HR 落地   |


### 9.3 红线（保持）

- 侵权封店等主观原因：扣绩效直至赔偿等，按原制度。  
- 价格设置错误造成亏损：承担约定比例损失。
