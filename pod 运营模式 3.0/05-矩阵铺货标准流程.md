# 矩阵铺货标准流程

> 从确定一个细分赛道到系统化上架的标准操作流程。这不是随机出图，是围绕同一人群覆盖多个表达维度的矩阵展开。阶段一由 **独立运营** 个人执行（见 `07`），不必拆成「研究 / 铺货」两岗。

---

## 总流程

```
确定三级细分赛道
    ↓
填写矩阵表（4 个维度 × 多个选项）
    ↓
组合生成款式清单
    ↓
批量出设计
    ↓
制作产品链接（标题 + 标签 + 主图）
    ↓
上架到店铺
    ↓
3-7 天看数据 → 进入筛选流程
```

---

## 第一步：确定三级细分赛道

### 前置检查：人群会在电商平台买T恤吗？

在选定赛道之前，先过三个问题：

1. **这群人在我们的平台上活跃吗？**（TikTok Shop / Shopee / Temu 的用户画像是否覆盖他们）
2. **这群人会穿印花T恤表达身份吗？**（有些群体穿制服或文化上不穿印花T恤）
3. **真正的买家是谁？**（可能是本人，也可能是配偶/家人/朋友送礼——买家的消费习惯比穿着者更重要）

三个问题中任何一个答案是"不确定"，这个赛道就不应该优先做。

### 选取赛道

从 `03-菲律宾细分赛道清单.md` 或 `04-欧美细分赛道清单.md` 中选取一个三级细分人群。

**合格的三级示例**：

- Shih Tzu Mom（菲律宾）
- Night Shift Nurse PH（菲律宾）
- Golden Retriever Mom（欧美）
- Boy Mom（欧美）

**不合格（太泛）**：

- Dog Lover
- Nurse
- Mom

## 第二步：填写矩阵表

每个三级赛道按以下 4 个维度展开，每个维度列出 3-5 个选项：

### 矩阵表模板


| 维度     | 选项 1 | 选项 2 | 选项 3  | 选项 4  | 选项 5  |
| ------ | ---- | ---- | ----- | ----- | ----- |
| **情绪** | 搞笑自嘲 | 温馨感动 | 骄傲自豪  | 日常吐槽  | 励志正能量 |
| **风格** | 极简文字 | 卡通插画 | 梗图风   | 复古    | 手写字体  |
| **语言** | 英文   | 本地语言 | 双语混搭  | —     | —     |
| **场景** | 日常穿  | 生日礼物 | 节日/纪念 | 职场/工作 | 情侣/亲子 |


### 实际填写示例：Shih Tzu Mom（菲律宾）


| 维度     | 选项                                                                                                                                    |
| ------ | ------------------------------------------------------------------------------------------------------------------------------------- |
| **情绪** | 搞笑（"One more Shih Tzu won't hurt"）/ 温馨（"My heart belongs to a Shih Tzu"）/ 自豪（"Proud Shih Tzu Mom"）/ 吐槽（"Shih Tzu hair on everything"） |
| **风格** | 极简文字 / 卡通 Shih Tzu 插画 / 梗图截图风 / 手写体                                                                                                   |
| **语言** | 英文 / Tagalog / 混搭（"Ang cute ng aso ko, Shih Tzu kasi"）                                                                                |
| **场景** | 日常穿 / 生日礼物 / 给狗过生日 / 遛狗场景                                                                                                             |

## 第三步：组合生成款式清单

从矩阵表中选取维度组合，生成具体的款式列表。不需要穷举所有组合，优先选最有潜力的组合。具体首批数量由运营根据赛道竞争情况和自身产能决定，不设硬性下限。

### 款式清单模板


| 编号      | 赛道           | 情绪  | 风格   | 语言      | 场景  | 文案/设计概要                                    |
| ------- | ------------ | --- | ---- | ------- | --- | ------------------------------------------ |
| STM-001 | Shih Tzu Mom | 搞笑  | 极简文字 | 英文      | 日常  | "Sorry I can't, my Shih Tzu needs me"      |
| STM-002 | Shih Tzu Mom | 搞笑  | 卡通插画 | 英文      | 日常  | Shih Tzu 插画 + "Just one more"              |
| STM-003 | Shih Tzu Mom | 温馨  | 手写体  | 英文      | 礼物  | "Best Shih Tzu Mom Ever" 手写风               |
| STM-004 | Shih Tzu Mom | 搞笑  | 梗图风  | Tagalog | 日常  | "Ang Shih Tzu ko, mas mahal pa sa jowa ko" |
| ...     | ...          | ... | ...  | ...     | ... | ...                                        |


**编号规则建议**：赛道缩写 + 三位数字

- STM = Shih Tzu Mom
- NSN = Night Shift Nurse
- GRM = Golden Retriever Mom
- BYM = Boy Mom

## 第四步：批量出设计

### 设计执行要求

**文字类设计（最快，优先做）**：

- 字体选择：根据情绪选字体（搞笑 → 粗体/手写，温馨 → 衬线/草书，自嘲 → 无衬线/极简）
- 颜色：2-3 色以内，不要花哨
- 排版：居中为主，文字清晰可读
- 工具：Canva / AI 生成 / Photoshop 模板

**插画类设计**：

- 可以用 AI 工具生成基础插画，再加文字
- 卡通风格比写实风格更适合 POD
- 确保插画与赛道直接相关（不是泛泛的"可爱动物"，是"Shih Tzu 的具体样子"）

**梗图类设计**：

- 参考目标人群社群里的热门梗图格式
- 改编文案，不要直接搬运
- 梗图风格在菲律宾和欧美年轻人群中转化率高

### 设计检查清单

每个设计上架前，过一遍这个清单：

- 看到这个设计，能在 1 秒内知道是给谁的吗？
- 文案有没有"代入感"——目标人群看到会觉得"这说的是我"？
- 文字在手机小屏上能清晰看到吗？
- 配色是否干净？有没有超过 3 种颜色？
- 是否跟同批次的其他设计有明确区分（不是换个词就算新款）？

## 第五步：制作产品链接

### 标题公式

**菲律宾线**：

```
[核心关键词] + [人群词] + [情绪/场景词] + Funny/Cute T-Shirt
```

举例：`Shih Tzu Mom Funny Dog Lover T-Shirt Philippines`

**Temu 全托管线**：

```
[核心关键词] + [人群词] + [场景词] + [风格词] + T-Shirt
```

举例：`Golden Retriever Mom Funny Dog Lover Gift T-Shirt`

### 标签/关键词

每个款式准备 10-15 个关键词，覆盖：

- 品种/赛道核心词（shih tzu, golden retriever）
- 角色词（mom, dad, owner, lover）
- 场景词（birthday gift, funny, cute）
- 长尾词（shih tzu mom shirt, golden retriever gift for her）

### 主图要求

- 第一张主图：产品穿着效果图，设计清晰可见
- 如果平台允许多图：加一张设计细节图 + 一张场景图
- 主图决定点击率，是最重要的转化要素

---

## 第六步：上架

### 上架规则

- 一个赛道的首批款式全部上架到对应人群方向的店铺（一个店只做一个人群，见 `02`）
- 记录上架时间，方便后续按时间节点看数据

### 上架节奏

- 不要一天全部上完。建议每天上架 10-15 个，分 2-3 天完成一个赛道的首批
- 原因：平台对新品有流量窗口，分批上架可以让每个款式都获得初始曝光

### 必须记录的信息

每个款式上架后，记录到数据表：


| 字段   | 说明                                  |
| ---- | ----------------------------------- |
| 编号   | 按编号规则                               |
| 所属赛道 | 三级细分                                |
| 平台   | TikTok / Shopee / Temu半托管 / Temu全托管 |
| 上架日期 | 精确到天                                |
| 文案方向 | 情绪+语言                               |
| 设计风格 | 极简/插画/梗图等                           |


---

## 第七步：进入数据筛选

上架后按 `08-数据筛选规则.md` 的标准，分时间节点判断每个款式的去留。

### 快速判断表


| 时间       | 看什么      | 动作                              |
| -------- | -------- | ------------------------------- |
| 第 1-3 天  | 曝光量、点击率  | 无曝光 → 检查标题/标签；有曝光无点击 → 换主图      |
| 第 4-7 天  | 收藏/加购、出单 | 有收藏无单 → 优化价格/详情页；有出单 → 标记进入放大候选 |
| 第 7-14 天 | 持续出单情况   | 持续出单 → 进入放大期；偶尔出单 → 观察；无单 → 淘汰  |

## 完整操作示例

以 "Night Shift Nurse PH" 为例，从头到尾走一遍：

**步骤一** — 赛道确认：Night Shift Nurse（菲律宾护士夜班人群）

**步骤二** — 矩阵填写：


| 维度  | 选项                      |
| --- | ----------------------- |
| 情绪  | 自嘲苦笑 / 自豪 / 搞笑 / 温馨     |
| 风格  | 极简文字 / 护士卡通 / 梗图 / 手写   |
| 语言  | 英文 / Tagalog / 混搭       |
| 场景  | 上班穿 / 送同事礼物 / 毕业礼物 / 日常 |


**步骤三** — 生成 25 个款式（示例前 5 个）：


| 编号      | 情绪  | 风格  | 语言      | 文案                                                   |
| ------- | --- | --- | ------- | ---------------------------------------------------- |
| NSN-001 | 自嘲  | 极简  | 英文      | "Night shift: where coffee meets chaos"              |
| NSN-002 | 自嘲  | 极简  | Tagalog | "Walang tulog, walang pera, pero nurse pa rin"       |
| NSN-003 | 自豪  | 手写  | 英文      | "Filipino Nurse – Saving Lives Worldwide"            |
| NSN-004 | 搞笑  | 梗图  | 混搭      | "Nurse ako, ano superpower mo?"                      |
| NSN-005 | 温馨  | 卡通  | 英文      | 护士插画 + "Not all heroes wear capes, some wear scrubs" |


**步骤四** — 出设计（按文字类优先，批量完成）

**步骤五** — 写产品链接，上架到店铺

**步骤六** — 3 天后看数据，7 天后做筛选判断
