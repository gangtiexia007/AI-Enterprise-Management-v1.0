# 三阶段执行手册

> 测试 → 放大 → 做深。每个细分赛道都要走完这三步。不要跳步。与 **有效链接、爆款** 考核及周复盘节奏对齐 `08`、`07`；店铺架构规则见 `02`。

---

## 阶段 1：测试期

### 目标

用最小的成本和时间，验证一个细分赛道是否值得深耕。

### 执行标准


| 项目        | 要求                   |
| --------- | -------------------- |
| 每个赛道首批款式数 | 覆盖矩阵表主要组合即可（具体数量以团队实际产能和赛道情况定） |
| 设计质量      | 够用即可（70 分水平），不追求完美   |
| 上架节奏      | 每天 10-15 个，2-3 天完成一批 |
| 观察周期      | 最短 3 天看点击，7 天做最终判断   |
| 同时测试的赛道数量 | 3-5 个（不要太多，管不过来）     |


### 日常操作流程

**第 1-2 天**：出设计 + 上架

1. 确定本批要测试的三级赛道（参考 `03`/`04`）
2. 按矩阵表展开，批量出设计（流程见 `05`）
3. 写产品链接（标题+标签+主图），上架
4. 记录每个款式的上架时间和基本信息

**第 3 天**：第一轮数据检查

- 看曝光量：没曝光 → 标题/标签有问题，修改后重新观察
- 看点击率：有曝光无点击 → 主图有问题，换图
- 看收藏/加购：有收藏说明赛道方向对了

**第 7 天**：最终判断

- 按 `08-数据筛选规则.md` 对每个款式做分类：
  - **A 类（有出单）**→ 进入放大期候选
  - **B 类（有点击/收藏但无单）**→ 优化产品链接后再观察 3 天
  - **C 类（无反应）**→ 淘汰

### 测试期的关键纪律

1. **不要恋战**：一个赛道测了 7 天没反应，果断换下一个
2. **不要追求完美**：测试期的设计只要能看清楚文案+传达情绪就行
3. **不要一次测太多**：3-5 个赛道同时测是上限
4. **必须记录数据**：没有数据的测试等于没测

## 阶段 2：放大期

### 目标

把测试期验证的有效款式放大出单量，最大化单个赛道的收益。

### 进入条件

一个款式进入放大期的标准：

- 7 天内有出单（最核心条件）
- 或者：点击率 > 平台平均值 + 收藏率 > 2%（虽然没出单但有明显兴趣信号）

### 放大的四个动作

#### 动作 1：做变体（最重要）

一个有数据的设计，做 5-10 个变体：


| 变体维度 | 操作         | 举例                                                           |
| ---- | ---------- | ------------------------------------------------------------ |
| 换文案  | 同一个赛道的不同表达 | "Just one more Golden" → "I promise this is the last Golden" |
| 换配色  | 同设计不同颜色方案  | 黑底白字 → 白底彩色 → 深蓝底                                            |
| 换字体  | 同文案不同字体风格  | 粗体 → 手写 → 复古                                                 |
| 换排版  | 同文案不同布局    | 居中 → 弧形 → 分行                                                 |
| 换载体  | 如果平台支持     | T 恤 → 帽子 → 马克杯（Temu 全托管可能受限）                                 |


**变体的原则**：保持赛道和情绪不变，只改表现形式。不是重新设计，是微调。

#### 动作 2：方向确认，围绕人群做深

- 方向确认标准见 `02`（7 天内 ≥ 3 款出单）
- 确认后这个店只围绕该人群方向积累款式
- 店铺内做好分类：按系列/场景组织
- 统一店铺视觉，让买家感觉"这个店都是我喜欢的"

#### 动作 3：跨平台分发

测试可能在 TikTok 上跑的，放大时同步到 Shopee 和 Temu 半托管：


| 原始平台      | 分发到        | 注意事项                   |
| --------- | ---------- | ---------------------- |
| TikTok PH | Shopee PH  | 标题和标签需要针对 Shopee 搜索优化  |
| TikTok PH | Temu半托管 PH | 价格要符合 Temu 的定价策略       |
| Shopee PH | TikTok PH  | 可以尝试用短视频形式推            |
| Temu全托管   | —          | Temu 全托管是独立的欧美线，不跟菲律宾混 |


**菲律宾线三平台共享同一套设计库**，只需要调整产品链接适配各平台规则。

#### 动作 4：广告/流量配合


| 平台      | 推流方式                             |
| ------- | -------------------------------- |
| TikTok  | 短视频展示（穿着效果+场景）→ 小预算跑量 → 看投产比决定加码 |
| Shopee  | 搜索广告（关键词竞价）→ 优先投有出单的款            |
| Temu半托管 | 平台自动推荐为主，优化标题标签获取更多自然流量          |
| Temu全托管 | 主要靠自然流量 + 平台活动，广告选项有限            |


**广告预算原则**：

- 测试期不投广告（靠自然流量验证）
- 放大期小预算测试（每款每天 ¥10-20）
- 看投产比：投产比 > 2 加码，投产比 < 1 停投
- 永远先有自然出单再考虑投广告

### 放大期的节奏


| 时间    | 动作                   |
| ----- | -------------------- |
| 第 1 周 | 做变体（5-10 个/爆款），方向确认后围绕人群做深 |
| 第 2 周 | 跨平台分发，开始小预算广告测试      |
| 第 3 周 | 看数据，加码有效款，淘汰无效变体     |
| 第 4 周 | 评估该赛道整体表现，决定是否继续加深   |

## 阶段 3：做深期

### 目标

在一个细分赛道中做到足够深，让买家搜索这个关键词时看到的大部分结果都是你的。

### 进入条件

- 该赛道已有 50+ 款式在售
- 有稳定的周出单（不是偶发的几单）
- 已经有多个"有效款"在持续出单

### 做深的两个动作

#### 动作 1：系列化

把零散的款式组织成系列：


| 系列名  | 内容        | 举例                             |
| ---- | --------- | ------------------------------ |
| 品种系列 | 按不同狗品种做系列 | Golden 系列、Frenchie 系列、Corgi 系列 |
| 场景系列 | 按使用场景     | 生日礼物系列、日常穿系列、节日系列              |
| 风格系列 | 按设计风格     | 极简文字系列、卡通插画系列                  |
| 情感系列 | 按情绪类型     | 搞笑系列、温馨系列、自豪系列                 |


系列化的好处：

- 买家买了一个，会去看同系列的其他款
- 提高客单价和店铺停留时间
- 平台算法更容易理解你的店铺定位

#### 动作 2：视觉统一

- 所有设计用统一的配色系统
- 统一的字体风格（2-3 种字体以内）
- 统一的主图模板（产品效果图风格一致）
- 店铺头图/横幅能体现赛道定位

## 常见错误警告


| 错误          | 正确做法                |
| ----------- | ------------------- |
| 跳过测试期直接做深  | 先用数据确认方向，再围绕人群做深    |
| 测试期就追求设计完美  | 测试期 70 分设计就够，放大期再精修 |
| 爆款不做变体      | 一个爆款至少做 5-10 个变体    |
| 变体改动太大      | 变体是微调，不是重新设计        |
| 不做跨平台分发     | 菲律宾线三平台共享设计库，必须同步   |
| 做深期不做系列化    | 散装款式没有竞争壁垒，必须系列化    |
| 过早投广告       | 先有自然出单，再考虑广告加码      |
