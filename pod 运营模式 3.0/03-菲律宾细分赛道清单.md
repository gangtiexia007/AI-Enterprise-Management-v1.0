# 菲律宾细分赛道清单

> 菲律宾线（TikTok + Shopee + Temu半托管）通用。每个赛道拆到三级以下后才能开始出设计。清单为 **选品参考**，由独立运营自选方向（`07` 模式 D）。

---

## 拆分层级说明


| 层级  | 含义    | 举例                   |
| --- | ----- | -------------------- |
| 一级  | 大类    | 宠物                   |
| 二级  | 人群    | 养狗人                  |
| 三级  | 细分人群  | 西施犬妈妈                |
| 四级  | 场景/时机 | 生日 / 搞笑日常 / 礼物       |
| 五级  | 表达风格  | 自嘲风 / 温馨风 / Tagalog梗 |


**原则**：

1. **前置条件——人群必须会在电商平台买T恤**：选任何赛道前先确认：这群人有线上消费习惯吗？会穿印花T恤表达身份吗？真正的买家是谁（本人还是配偶/家人送礼）？不满足就不选。
2. 一级、二级层面的设计（如 "Dog Lover"）不做。必须拆到三级以下才开始出设计。

## 使用方式

1. 从上述清单中选择要测试的赛道（建议首批选 3-5 个三级细分）
2. 按照 `05-矩阵铺货标准流程.md` 的流程，用矩阵展开每个三级赛道
3. 上架后按 `08-数据筛选规则.md` 判断去留
4. 方向确认后围绕该人群做深（店铺规则见 `02`）

**首批推荐测试**（菲律宾市场最稳的起手赛道）：

1. Shih Tzu Mom — 宠物线最稳
2. Night Shift Nurse — 职业线共鸣最强
3. NBA/Basketball Pinoy — 覆盖面最广
4. OFW Family — 情感浓度最高
5. Tagalog 打工人日常 — 最容易出梗
